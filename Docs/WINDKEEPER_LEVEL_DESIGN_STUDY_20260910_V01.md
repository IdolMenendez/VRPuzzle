# 让风车重新运转：关卡设计与素材审视

2026-09-10。只讨论游戏与素材，不讨论发行。评分为基于当前代码、关卡与截图的设计判断，不是用户调研分数。

## 现在打几分

以完整游戏的关卡设计衡量，总体 **5/10**。现有内容能体现亲手拼装的潜力，但“一个模型变成一堆零件，再拼回去”的重复仍占主导。

| 维度 | 当前评分 | 理由 |
| --- | --- | --- |
| 题材和氛围 | 7/10 | 微缩模型与暖木工坊有吸引力，符合 VR 的拿取观察优势 |
| 关卡变化 | 4/10 | 五个题材的操作循环相近，尚缺每关自己的规则与高潮 |
| 目标与引导 | 5/10 | 有提示和进度，但不够体现为什么要做、现在应该注意什么 |
| 素材对玩法的支持 | 5/10 | 近看细节多，但材质偏混、部分部件轮廓和完整性不足 |
| 完成反馈与连续体验 | 4/10 | 拼完后的把玩内容、收藏入口、中途续玩尚不完整 |

这些问题可以显著改善。是否最终达到 8/10，必须由真实玩家体验证明，不能用新加了几个系统来给自己打高分。

## 关卡设计原则

每关围绕一个可理解的小愿望，例如“让停下来的风车重新转动”。为关卡写四句话：玩家看见什么问题，第一步能做什么，中间学到什么，最后亲手改变了什么。

节奏采用“成功一次 → 出现新关系 → 作一次选择 → 看见作品变化 → 亲手完成”。部件数量不等于深度。可以自由先后的装配分支要保留；顺序限制必须能从支撑、遮挡或传动关系理解。

不把零件都同时摊出来制造复杂感，不用长时间举手、隐蔽小部件或不稳定追踪制造难度。提示帮助观察，不惩罚需要辅助的玩家。完成后让模型产生有意义的变化，并允许停留把玩。

## 风车关卡的新设计

目标：让风车重新运转。预计 5–10 分钟是初期测试假设，尚未实测。

1. **建起它的家。** 先给一个明显的底座，成功后开放花园与塔体两条小分支；花园可早做也可最后做。让玩家有选择，而不是所有步骤都只能照顺序。
2. **接住风。** 塔体支撑阳台和屋顶，屋顶提供轴的安装位置，装好轴再开放两组叶片。让顺序来自机械关系。
3. **亲手唤醒。** 拼完不会立刻跳走。玩家沿轮轴转动叶片半圈，风车开始缓慢转动，暖光亮起，进入可停留欣赏的完成状态。

现有八个部件的样板依赖：底座 → {花园，塔身}；塔身 → 阳台 → 屋顶 → 轮轴 → {叶片组一，叶片组二}。

正式新素材应进一步把轴孔、接口形状和装配方向做出来，让用户看得懂为什么还不能装；当前样板主要以部件显隐和提示验证节奏，没有把原素材重建成新的真实机械结构。

## 怎样让其他关卡有自己的性格

| 关卡 | 独特体验 | 玩家亲手完成的最后动作 |
| --- | --- | --- |
| 花园小屋 | 分支建造、屋顶与墙面对应；最后自行选择少量花园布置 | 开门亮灯，让小屋有人生活的感觉 |
| 帆船 | 船体支撑与桅杆层级，帆面方向辨认 | 拉升船帆，船在微缩水面上轻轻起伏 |
| 铁塔 | 四边对称、结构承重与平台闭合 | 接通塔灯，看到结构从下到上被点亮 |
| 宝塔 | 层级与屋檐形状辨认、重复中的变化 | 悬挂并拨动风铃 |
| 风车 | 轴与叶片的装配关系 | 亲手转动叶片，启动风车 |

这些是关卡提案。此次只制作风车独立样板，没有把其他四关的动作做进游戏。

## 素材判断与取舍

现有工坊可继续使用，优先清理材质、照明、零件区与背景的视觉竞争。重复柜架和偏暗空间不能仅靠再加灯解决，后续要控制背景细节密度。

现有风车可用于玩法验证：已经具有八个语义模块，轮轴与叶片能拆开验证装配。它的写实旧石材、金属反光、细碎花草与部件断面，距离概念图中的完整手工收藏品仍有差距。不要把提亮旧素材描述为换成了新素材。

现有帆船及细杆地标的细节密度过高，部分长条、薄片部件单拿出来不好理解。必须逐件审视背面、厚度、轮廓和抓取位置。改成有框架、有实体体积的完整模块，不能把漂亮的整体模型随意切碎就算完成设计。

独立 Garden 的颜色和轮廓更亲切，可用于确定新的风格方向；它仍需通过完整部件和实际装配检验，不能当作现成替换包直接混进本关。

新主角的优先级：清楚的轮廓和连接关系 > 中等尺度的材质与倒角 > 装饰细节。木、浅色灰泥/陶瓷、克制黄铜形成层级。需要专门设计的拼装资产采用统一风格，不混多个素材包充当主角。

## 本轮实际制作内容

- 一张新风车关卡美术设计板，使用内置 imagegen 生成。包含整体目标、搭建/叶片/启动三个节奏和材质方向；它是概念图，不是新的3D资产或游戏截图。
- 一个独立 Unity 风车样板：复用现有八个部件，加入分支依赖、按可装关系逐步出现的零件、明确章节、免费提示、独立逐件存档、鼠标拖放和转动叶片后的完成反馈。
- 一份素材来源清单和实际下载的木材贴图样本。

样板是桌面关卡设计验证，用鼠标的平面移动和旋转辅助体验节奏。没有接入当前 APK 的选关入口，没有证明头显手感；VR 需要单独接入、校准和佩戴测试。现有 V82 场景、正式构建列表及 APK 保持原有版本。

## 如何体验样板

在 Unity 打开场景，然后 Play；也可以使用菜单 Personally Puzzled XR → Design Study → Play Windmill Study。

鼠标拖动部件到出现的轮廓附近，松开吸附；Q/E 转动拿着的部件；H 请求提示；R 或 Start over 需再次确认才会重开。完成全部八件后，按住叶片附近并绕轮轴拖动半圈，两种方向都可以，随后风车持续转动。

## 下一步怎样判断是否真的更好

让没见过开发过程的人分别试玩原关与样板，轮换体验顺序。观察他是否知道先拿什么，是否理解部件关系，是否主动使用提示，是否想留在完成状态把玩，是否愿意再做另一个模型。记录实际时间，但不把更快完成简单等同更好玩。

如果新手仍在寻找入口或反复操作失败，先改交互。如果操作顺畅却觉得重复，增加可理解的结构选择与完成互动。如果玩家觉得作品不值得收藏，才集中重做主角美术。用玩家实际卡住的位置决定优先级。
